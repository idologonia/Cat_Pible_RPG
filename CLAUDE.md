# CAT & PIBBLE RPG — інструкції для Claude

Браузерна піксельна Action RPG у стилі Diablo. Герої — котики й пібулі (лицар / маг / лучник), вороги — щури (розбійники, Королівська гвардія). **Уся гра — ОДИН офлайн-файл `cat-pibble-rpg.html`** (~9000 рядків, ~740 КБ): HTML + CSS + один `<script>`, без зовнішніх бібліотек, спрайтів чи аудіофайлів (усе процедурне).

## Правила співпраці (від автора — дотримуватися завжди)

- Спілкування й підсумки — **українською**. Весь текст у грі — українською.
- Працюємо **етапами**. Наприкінці кожного етапу — короткий звіт українською: що додано, як працює, на що звернути увагу під час тестування.
- Автор сам грає й тестує після кожного етапу, а потім дає відгук. Не додавати великих систем, про які не домовлялися. Не ставити заглушок замість механік.
- **Усі числа балансу — у `CONFIG`** (на початку скрипту), а не розкидані по коду.
- Прогресія навмисно повільна: досвіду й монет мало, предмети рідкісні, вороги ростуть разом із героєм (див. `leveling`, `levelGap`, `locBonus`, `loot`). Не роби гру легшою без прохання.
- Зворотна сумісність збережень обов'язкова: нові поля в `Game.flags` / `heroData` мають мати дефолти (`f.x ?? …`, `f.x || (f.x = …)`) або йти через `SaveSys.migrate`.
- Автор грає на ПК і на телефоні (сенсорне керування, мобільний HUD). Перевіряй, що UI не ламається на вузькому екрані.

## Як влаштований файл

Великий файл: не читай його повністю. Шукай за якорями (`Grep`), а потім читай із `offset`/`limit`. Розділи позначено коментарями `/* ===================== … ===================== */`:

| Розділ | Що всередині |
|---|---|
| `1. CONFIG` | `const CONFIG = {…}` — усі числа (бій, рівні, лут, доба, погода, корчма…) |
| `2. ДАНІ` | `RACES`, `ITEM_BASES`, `CLASSES` |
| `3. УТИЛІТИ` | `clamp`, `mulberry32`, `hash2`, `$` |
| `4. СПРАЙТИ` | `Pix` (R/P/poly/line/ellipse), `cachedSprite(key,w,h,ax,ay,fn,outline)`, `sprite*()` |
| `5. СВІТ` | `T` (тайли), `TILE_INFO`, `class World`, `build*` для локацій, генератор підземель, `LOCATIONS` |
| `6. СУТНОСТІ` / `6б. БІЙ` | `Critter`, `makeCombatant`, `Nav` (A*), `ENEMY_AI`, `hitTarget` / `dealRaw` / `heroTakeDamage`, статуси `st` (freeze, stun, slow, burn, poison, weak) |
| `7. ВВІД`, `8. РЕНДЕР`, `9. UI` | `Input`, `Render` (ізометрія 2:1: `proj = ((x−y)*16, (x+y)*8)`), `UI` (панелі, діалоги, тости, банери) |
| `ЗБЕРЕЖЕННЯ` | `SaveSys` (localStorage `cpr_save_N`, `serialize`, `migrate`), `requestAutosave(why)` |
| `КВЕСТИ` | `QUESTS`, `Quests` (`emit`, `advance`, `step`, `target`, `state`) |
| далі | дерева навичок, місто (коваль, алхімія, сховище, дошка), зв'язки локацій і світова мапа (`LINKS`, `WORLD_NODES`, `TRAVEL_POINTS`, `nextHop`) |
| `ЕТАП 12 … ЕТАП 24` | кожен пізній етап — окремим блоком (див. `docs/CHANGELOG.md`) |
| `ЗВУК І МУЗИКА` | `AudioSys` (Web Audio-синтез), `MUSIC`, `SFX`, `trackFor(loc)` |
| `10. ГРА` | `const Game = {…}`: `init`, `loadLocation`, `changeLocation`, головний цикл, бій, смерть |

### Основні патерни

- **Розширення через обгортки.** Пізні етапи не переписують старий код, а обгортають функції:
  `{const _f=fn; fn=function(...a){ …; return _f(...a); };}`
  або хелпер `wrap(obj,'method',after)` усередині `install*Hooks()` (викликаються в `Game.init`). Нові фічі роби так само: окремий блок `/* ===== ЕТАП N: … ===== */` перед `/* ---------- Вступ ---------- */`.
- **Локація** — запис у `LOCATIONS` (`build(W,rng)`, `w`, `h`, `seed`, `start`), а також `LINKS`, `WORLD_NODES`, `TRAVEL_POINTS`, `LOC_MIN`, `WEATHER_P`, трек у `trackFor`. Переходи між локаціями: `W.exits` (зона, куди треба зайти) або `W.portals` з об'єктом-дверима (`interact`). Підземелля мають `dungeon:true, noCache:true, parent`. Інтер'єри: `W.indoor = true` і `mapAs` (як корчма `inn` → `cheese`).
- **NPC**: `EXTRA_NPCS[loc]`, `NPC_GREET`, `NPC_TALK`, `QUEST_TALK`, а також `NPC_HOME` / `NPC_HOME_DYN` (потрібні, щоб квестова мітка знайшла NPC).
- **Стан світу** — `Game.flags` (зберігається). Його застосовують `applyWorldFlags` / `applyWorldFlags2` / `applyWorldFlags3` після завантаження локації.
- **Дошки контрактів**: `boardState(id)`, `genOffer(bid)`, `takeContract`, `finishContract`. Ідентифікатори дошок: `city` → `board`, `village` → `vboard`, `tavern` → `tboard`.
- **Союзники**: `Ally` / `Guard` / `Escortee` (extends `Critter`). Вороги б'ють союзників через `Game._aiTarget`.
- **Звук**: `AudioSys.play('name')`, нові ефекти додаються в `SFX`, музика — в `MUSIC`.
- **Спрайти** завжди кешуються через `cachedSprite` з унікальним ключем. Кольори — піксель-арт-палітра, контур `OUTLINE`.

### Кооператив (етап 23, блок `ЕТАП 23: КООПЕРАТИВ`)

- `Net` — кімната й обмін повідомленнями. `Net.role`: `null` / `'host'` / `'guest'`. `Net.live()` — є з ким грати (тоді паузи немає).
- Зв'язок (етап 24): гра бачить лише канали гравців — `Net.links[pid]` у хоста, `Net.hostLink` у гостя (`{kind:'bc'|'rtc', send, close}`). Два шляхи: вкладки одного браузера (`BroadcastChannel`) та інтернет — WebRTC data channel напряму; знайомство (стук → пропозиція → відповідь) через `Signal` — одночасно ntfy-сумісний сервіс `CONFIG.coop.signalUrl` (`POST /тема`, `GET /тема/sse`) і MQTT-брокери `CONFIG.coop.mqttUrls` (власний мінімальний клієнт `MqttLink`); повтори відкидаються за `mid`. STUN/TURN — `CONFIG.coop.iceServers`.
- Третій шлях — власний сервер `server/coop-server.py` (лише стандартна бібліотека Python): WebSocket `/ws?room=КОД&id=…`, пересилає за полем `to`, роздає гру з `window.CPR_SERVER`. У грі — поле «Сервер» (`coopServerBase()`, `Net.openServer`); канал `kind:'srv'`.
- Згорнута вкладка: браузер зупиняє `requestAnimationFrame`, тому в кооперативі гру крутить `setInterval`, що надолужує час (`bgStep`, `bgMaxSteps`); про згортання сторони повідомляють одна одну (`vis`), і тоді діє довший тайм-аут `timeoutHidden`.
- **Хост рахує світ** (вороги, здобич, час, погода, прапорці, завдання). **Кожен гравець рахує свого героя**: `Game.hero` / `heroData` / `derived` завжди означають *свого* героя, тому навички, інвентар і дерево навичок працюють без змін.
- Інші гравці — `Net.remotes` (`Critter` з `isHero` і `isRemote`). Вороги обирають ціль через `coopTargetHero(e)`; шкода чужому герою — `Net.hurtRemote` (через `Game._aiTarget`), відкидання — `Net.knockRemote`.
- У гостя вороги — копії (`mirror:true`, `coopMirrorUpdate`), побудовані з опису хоста (`Net.descOf` → `makeCombatant(spawn)`). Удари гостя (`hitTarget` / `dealRaw`) ідуть хосту як `{d, st, kv}` (`Net.reportHit`); вбивства й нагороди вирішує хост (`kill`).
- Підземелля: хост пересилає насіння (`Net.seeds`), тож коридори однакові.
- Герої гостей зберігаються в `Game.flags.party[ім'я гравця]` (лише в хоста). Гостю прапорці надсилаються без `party` (`Net.flagsForGuest`).
- У гостя вимкнено: збереження, переходи між локаціями, розмови / двері / торгівлю, події в дорозі, набіги, власних союзників, зміни завдань.
- Тести: `tests/legacy/test27.py` (дві вкладки одного браузера), `tests/legacy/test28.py` (WebRTC між різними профілями; знайомство через локальну імітацію `tests/ntfy_mock.py`), `tests/legacy/test29.py` (через сервер на ПК).

## Перевірка після кожної зміни

```bash
pip install -r requirements.txt && python -m playwright install chromium   # один раз
python tests/check_syntax.py        # синтаксис JS (потрібен Node.js)
python tests/run_all.py             # усі регресійні тести (Playwright, headless)
python tests/run_all.py test22      # лише один тест
```

- Тести в `tests/legacy/` запускають гру в headless Chromium, проганяють сценарії через `page.evaluate` і роблять скриншоти в `tests/shots/`. Тест пройшов, якщо в кінці виводу є `ERRORS []` (немає помилок сторінки).
- Для нової фічі пиши новий `tests/legacy/testNN.py` за тим самим зразком і переглядай скриншоти (рендер — це головне, що бачить гравець).
- Тести інколи «помирають» через баланс. Тоді вмикай героєві безсмертя: `Game.hero.iframe=99`, а в довгих тестах роби це через `setInterval`.

## Відомі нюанси

- Збереження лежать у `localStorage` браузера й прив'язані до адреси файлу. Нова версія файлу в іншому місці (особливо на телефоні) їх не бачить. Для цього є меню «Перенести збереження»: експорт і імпорт файлом `.json` або текстовим кодом.
- `#toast` має `pointer-events:none`, інакше тост перекриває кнопки діалогів.
- Вікно `#saveIO` має `z-index:40`, бо воно відкривається поверх паузи.
- Підземелля ставлять `W.dark`; ніч і погода в них та в інтер'єрах (`W.indoor`) не діють.
