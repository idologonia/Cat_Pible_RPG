# CAT & PIBBLE RPG

Піксельна Action RPG у браузері: котики й пібулі проти щурячої навали.

**Грати онлайн:** https://idologonia.github.io/Cat_Pible_RPG/ (працює і на ПК, і на телефоні).

**Грати офлайн:** завантаж `cat-pibble-rpg.html` і відкрий його в браузері. Інтернет не потрібен.

**Кооператив** (до 4 гравців): хост — «Пауза → Кооператив → Створити кімнату», друзі — «Кооператив» у головному меню, ім'я та код кімнати. Гра йде напряму між браузерами (WebRTC), для знайомства використовується сервіс ntfy.sh.

**Збереження** лежать у браузері. Щоб перенести прогрес у нову версію файлу або на інший пристрій, відкрий «Меню → Перенести збереження» і скористайся експортом та імпортом (файл `.json` або код). Онлайн-версія й локальний файл мають окремі збереження, тож для переходу між ними теж скористайся перенесенням.
