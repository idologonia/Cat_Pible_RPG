# Сервер гри на твоєму ПК

Поки сервер увімкнений, усі гравці грають у кооператив через нього — це працює між будь-якими мережами й країнами (наприклад, Україна ↔ Бельгія, мобільний інтернет). У грі у вікні «Кооператив» видно стан: **🟢 Сервер гри онлайн** або **🔴 Сервер гри офлайн**. Коли сервер вимкнений, гравці з'єднуються напряму, як і раніше.

Друзям нічого запускати не треба — гра сама знаходить твій сервер.

## Один раз

1. Відкрий https://github.com/idologonia/Cat_Pible_RPG → зелена кнопка **«Code»** → **«Download ZIP»**.
2. Розпакуй архів куди зручно (наприклад, на Робочий стіл). Усередині — папка **`server`**.

Більше нічого встановлювати не треба: якщо на ПК немає Python, сервер сам завантажить портативну версію; тунель Cloudflare теж завантажиться сам.

## Щоразу, коли хочете грати

1. Відкрий папку `server` і двічі клацни **`start-server.bat`**.
2. Дочекайся рядка **«СЕРВЕР ОНЛАЙН: https://…trycloudflare.com»** (перший запуск — до хвилини, бо завантажуються програми).
3. **Не закривай це чорне вікно**, поки граєте. Щоб вимкнути сервер — натисни в ньому `Ctrl+C` (тоді гравці одразу побачать «офлайн») або просто закрий вікно.
4. Грайте як завжди на https://idologonia.github.io/Cat_Pible_RPG/ — Пауза → «Кооператив» → має бути «🟢 Сервер гри онлайн» → «Створити кімнату». Друзі: «Кооператив» у головному меню → ім'я → код → «Через інтернет».

## Якщо щось не так

- Windows показує «Windows захистив ваш ПК» — натисни «Докладніше» → «Виконати в будь-якому разі» (це звичайний .bat-файл з гри).
- Вікно пише «Не вдалося завантажити Python» — перевір інтернет і запусти ще раз; або встанови Python з https://www.python.org/downloads/ (галочка «Add python.exe to PATH»).
- У грі довго «⏳ Перевіряю сервер гри…» або «🔴 офлайн», хоча вікно сервера відкрите — зачекай пів хвилини й відкрий вікно «Кооператив» ще раз.
- Інший порт: у `start-server.bat` додай `--port 9000` після `--public`.
