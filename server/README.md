# Сервер кооперативу на ПК

Сервер пересилає повідомлення між гравцями й роздає саму гру. З ним кооператив працює навіть там, де прямі з'єднання між браузерами не проходять (наприклад, мобільний інтернет).

## Один раз: що встановити (Windows)

1. **Python** — https://www.python.org/downloads/ → «Download Python». Під час встановлення постав галочку **«Add python.exe to PATH»**.
2. **cloudflared** (безкоштовний тунель, без реєстрації) — https://github.com/cloudflare/cloudflared/releases/latest → завантаж `cloudflared-windows-amd64.exe`, перейменуй на `cloudflared.exe` і поклади в цю папку `server`.
3. Завантаж гру з GitHub: на сторінці репозиторію «Code» → «Download ZIP», розпакуй. Потрібна вся папка: `cat-pibble-rpg.html` і папка `server` поруч.

## Щоразу, коли граєте

1. Двічі клацни **`start-server.bat`** — відкриється чорне вікно «Сервер кооперативу працює». Не закривай його.
2. Двічі клацни **`start-tunnel.bat`** — у вікні з'явиться адреса на кшталт `https://щось-там.trycloudflare.com`. Вона нова щоразу.
3. **Ти (хост):** відкрий гру як завжди (https://idologonia.github.io/Cat_Pible_RPG/), Пауза → Кооператив → у полі **«Сервер»** впиши `localhost:8787` → «Створити кімнату». Має з'явитися «🖥 Кімната на сервері».
4. **Друзі:** відкривають адресу тунелю `https://….trycloudflare.com` — гра відкриється вже налаштована на твій сервер. «Кооператив» → ім'я → код кімнати → «Через інтернет».

Збереження: ти граєш на звичному сайті, тож твої збереження на місці. Герої друзів зберігаються у твоєму збереженні.

## Якщо щось не так

- «python не є внутрішньою командою» — Python встановлено без галочки PATH: перевстанови з нею.
- Друзі не відкривають адресу тунелю — перевір, що обидва вікна (сервер і тунель) відкриті, і що адреса скопійована повністю.
- Інший порт: `python coop-server.py 9000`, тоді в тунелі `cloudflared tunnel --url http://localhost:9000`, а в грі `localhost:9000`.
